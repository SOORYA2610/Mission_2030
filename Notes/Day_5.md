# Web Data Scraper

A Python web scraper that collects book information from Books to Scrape.


## Features

- Scrapes book titles
- Extracts prices
- Extracts availability
- Handles pagination
- Exports data to CSV


## Technologies

- Python
- Requests
- BeautifulSoup
- CSV


## Output

The scraper collects 1,000 books from 50 pages.
